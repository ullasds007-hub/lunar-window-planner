Lunar Window Planner User Guide

Use the planner to find suitable times for Moon viewing or stargazing.

How to run the planner

Open a terminal in the folder containing api.py and run:

python -m uvicorn api:app --port 8002

Keep the terminal open and visit http://127.0.0.1:8002/ in your browser instead of double-clicking index.html.

Quick tutorial

  1. Under Location, select Mysuru for this demo.
  2. Set First observing night to 20 November 2026 and Last observing night to 22 November 2026.
  3. Under Observation goal, choose Moon viewing.
  4. Click Find Windows and review the results below the form.

Each observing night runs from local noon to noon the next day. The planner does not check weather.

A suggested window does not guarantee clear skies. Check your local weather and look for a spot with an unobstructed view.

Compare lunar sites and landing times

Open Compare landing sites. All times on this page are UTC.

Compare two sites at the same time

Select Try the south-pole site comparison. Both scenarios run from December 14, 2026 at 20:00 to December 15 at 02:00 UTC. The Sun and Earth are both above the modeled horizon for 3 h 34 min at Shackleton Rim and 6 h at de Gerlache Rim 1.

Compare two landing times at the same site

Open Edit sites and times, then Compare a landing delay. Select Try the Shackleton Rim example to compare the planned six-hour window with one beginning 72 hours later. For a custom comparison, set Scenario A's site and UTC start, enter a duration and delay, and select Run landing delay comparison.

Read and share the results

The visibility timeline shows whether the Sun, Earth, both, or neither were above the modeled horizon. Expand View visibility intervals (UTC) for the times and durations. The headline subtracts Scenario A's Both above time from Scenario B's. Use Export comparison CSV for the totals or Copy comparison link to save the inputs. Links using localhost or 127.0.0.1 work only on the machine running the planner.

The smooth-horizon model does not account for terrain shadows and does not guarantee power output or a working radio link.
